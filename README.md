- Governance, Risk & Compliance
- ISO/IEC 27001:2022
- NIST CSF 2.0
- Risk assessment and risk registers
- Control design and testing

- Audit evidence and remediation
- Third-Party Risk Management (TPRM)
- DPDP / GDPR privacy readiness
- IAM governance, RBAC, SoD and access reviews
- Cloud security governance
- Excel / Power BI reporting
- AI governance and AI risk

## Completed project: ISO 27001 Gap Assessment

The first completed project demonstrates an end-to-end simulated GRC workflow:

**Scope → Requirements → Controls → Evidence → Assessment → Risks → Findings → Remediation → Validation**

It includes a control matrix, risk register, evidence index, gap assessment, findings log, remediation roadmap and executive summary.

## Evidence standard

Completed projects should contain:
- README.md
- Risk register
- Control matrix
- Evidence index
- Findings log
- Remediation tracker
- Executive summary
- Screenshots / dashboards where useful
- Lessons learned

## Important

All work in this repository is simulated, lab-based or educational unless explicitly stated otherwise. No employer-confidential information, credentials, customer data or proprietary documents should be published.

## Portfolio quality rule

Quality and traceability matter more than repository count. Every completed project should show a clear chain from risk or requirement to control, evidence, finding, remediation and validation.
