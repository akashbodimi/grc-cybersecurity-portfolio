# Cyber Risk Register & Dashboard

**Status:** Planned — simulated environment

## Objective

Build a practical risk-management workflow from risk identification through treatment, monitoring and reporting.

## Risk fields

- Risk ID
- Asset / process
- Threat / scenario
- Vulnerability / weakness
- Existing controls
- Likelihood
- Impact
- Inherent risk
- Treatment decision
- Residual risk
- Risk owner
- Due date
- Status
- KRI / KPI

## Deliverables

- Risk methodology
- 10–15 sample risks
- Risk register
- Risk heatmap
- Treatment plans
- Ageing analysis
- Management dashboard

## Tools

Excel first; Power BI can be added later.
