# Cloud GRC Reference Sources

The assessment uses current public references to structure the simulated cloud GRC control themes.

- AWS Shared Responsibility Model: https://aws.amazon.com/compliance/shared-responsibility-model/
- AWS Well-Architected Security Pillar — Shared Responsibility: https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/shared-responsibility.html
- Microsoft Azure Shared Responsibility Model: https://learn.microsoft.com/en-us/azure/enclave/shared-responsibility-model
- NIST Cybersecurity Framework 2.0: https://www.nist.gov/cyberframework
- NIST SP 800-53 Rev. 5: https://csrc.nist.gov/pubs/sp/800/53/r5/final
- CIS Critical Security Controls v8.1: https://www.cisecurity.org/controls

These sources support the framework and shared-responsibility concepts used in the project. The workbook and artifacts are simulated and are not a certification, audit opinion or legal determination.
