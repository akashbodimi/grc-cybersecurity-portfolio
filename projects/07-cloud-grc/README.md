# Cloud GRC Assessment

**Status:** Planned — simulated cloud environment

## Objective

Assess cloud governance controls using shared-responsibility concepts and selected security requirements.

## Control areas

- IAM
- Logging and monitoring
- Encryption
- Backup and recovery
- Vulnerability management
- Configuration management
- Network segmentation
- Incident response
- Supplier governance

## Deliverables

- Cloud asset inventory
- Control mapping
- Gap assessment
- Evidence checklist
- Risk register
- Remediation roadmap
