# Cloud GRC Assessment Methodology

> Simulated portfolio methodology for Northstar Cloud Services Pvt. Ltd.

## Objective

Assess cloud governance by connecting the provider/customer responsibility boundary to customer-controlled security, compliance, resilience and audit evidence.

## Lifecycle

**Scope & Inventory → Shared Responsibility → Control Mapping → Evidence Review → Findings → Remediation → Validation → Management Reporting**

## Assessment Domains

- IAM and privileged access
- Network segmentation and exposure
- Logging and monitoring
- Encryption and key management
- Vulnerability and patch management
- Backup and recovery
- Secure cloud configuration / CSPM
- Incident response
- Data governance
- Change management
- Provider assurance / inherited controls

## Assessment Principle

A cloud service provider's assurance does not automatically demonstrate that the customer has configured its environment correctly. The portfolio therefore separates **inherited/provider responsibilities** from **customer implementation responsibilities** and documents the evidence expected for each.

## Risk Treatment

Findings are prioritized using business impact and control gap severity. Residual risk should only be reduced after remediation evidence is reviewed and validated.

This is a simulated internal assessment methodology, not a certification audit or legal opinion.
