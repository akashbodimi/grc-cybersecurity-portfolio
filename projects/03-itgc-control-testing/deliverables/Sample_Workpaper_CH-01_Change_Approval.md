# Sample Workpaper — CH-01 Change Approval

> Simulated portfolio work for Northstar Cloud Services Pvt. Ltd. Not a real client workpaper.

## Control

**Control ID:** CH-01  
**Control:** Production changes require documented approval before implementation except approved emergency changes.  
**Frequency:** Per change  
**Owner:** Change Manager  
**Control type:** Preventive

## Risk

Unauthorized or untested production changes may disrupt services or weaken the security and control environment.

## Test Objective

Assess whether sampled production changes were approved before implementation and retained an auditable trail.

## Population and Sample

**Population:** 42 simulated production changes during Q3 2026.  
**Sample:** 8 change tickets covering standard and normal changes.

## Evidence Reviewed

- Change ticket
- Business / technical approval
- Implementation timestamp
- Deployment record
- Closure evidence

## Sample Results

| Sample | Change | Approval | Timing Check | Result |
|---|---|---|---|---|
| CHG-01 | Application patch | Present | Before deployment | Pass |
| CHG-02 | Firewall rule update | Present | Before deployment | Pass |
| CHG-03 | OS upgrade | Present | Before deployment | Pass |
| CHG-04 | Database configuration | Present | Before deployment | Pass |
| CHG-05 | Network maintenance | Present | Before deployment | Pass |
| CHG-06 | IAM connector update | Present | Before deployment | Pass |
| CHG-07 | Monitoring agent update | Present | Before deployment | Pass |
| CHG-08 | Web configuration change | Present | Before deployment | Pass |

## ToD Conclusion

**Pass.** Approval is a defined prerequisite to production deployment and is supported by a traceable ticket.

## ToE Conclusion

**Pass.** All eight sampled changes contained evidence of approval before implementation.

This workpaper is intentionally limited to a simulated population and sample. It does not represent an opinion on any real organization.
