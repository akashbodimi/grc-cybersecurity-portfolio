# IAM Governance & Access Review

**Status:** Planned — simulated identity environment

## Objective

Demonstrate governance controls covering identity lifecycle, RBAC, privileged access, segregation of duties and periodic access recertification.

## Include

- Joiner / mover / leaver lifecycle
- RBAC matrix
- MFA governance
- Privileged access
- Segregation of Duties
- Quarterly access review
- Exceptions and approvals

## Deliverables

- IAM control matrix
- Role catalogue
- Access-review sample
- SoD conflict matrix
- Remediation log
- Management summary
