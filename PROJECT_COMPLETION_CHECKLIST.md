# GRC Portfolio Project Completion Checklist

- [ ] README explains the business scenario and objective
- [ ] Scope and assumptions documented
- [ ] Relevant framework / requirements identified
- [ ] Assets, processes or data flows identified
- [ ] Risks documented
- [ ] Controls documented
- [ ] Evidence requirements defined
- [ ] Testing / gap assessment performed
- [ ] Findings documented
- [ ] Remediation actions assigned
- [ ] Management / executive summary created
- [ ] Screenshots or sanitized evidence added where useful
- [ ] Lessons learned documented
- [ ] No credentials, secrets or confidential data
- [ ] Project clearly labeled as simulated/lab work
- [ ] Project linked from portfolio root README
